## Chess engine

| Asset | Source | Licence |
| --- | --- | --- |
| Stockfish 10 (WebAssembly build), `public/engine/stockfish.wasm.js` and `public/engine/stockfish.wasm` | npm package `stockfish.js` 10.0.2, source at <https://github.com/niklasf/stockfish.js> (upstream: <https://github.com/official-stockfish/Stockfish>) | **GPL-3.0** |

Stockfish is GPL software inside an otherwise closed-source app, so how it is used matters:

- It is shipped **unmodified**, as separate files, and runs as its own program in a Web Worker.
- Our code talks to it only through UCI, the standard text protocol for chess engines. None of its code is compiled into our bundle.
- Its full licence text is served next to it (`public/engine/COPYING.txt`), players are told what it is and under which licence on the "Play the computer" screen, and the source for this exact build is at the link above.

This arm's-length arrangement is how commercial chess sites generally ship Stockfish, but it is a legal question, not a technical one: **have a lawyer confirm it before launch.** If we ever modify the engine, the modified source must be published.

## Chess pieces: "Solid" (`src/games/chess/pieces/hub/`)

An original set drawn for this project: twelve SVG files generated by `scripts/makePieces.ts` (`npm run pieces`) from plain shapes written in that script. Solid bodies, dark outline, shading from the upper left. Not traced or derived from any other set. Original work, owned by the project. It is the default set; Chessnut and RhosGFX remain as choices.
